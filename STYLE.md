# User Interface

Kyros should feel like a meeting point between **Ancient Alexandria** and **the future of artificial intelligence**.

The interface should communicate permanence, intelligence and discovery—not trading, social media or consumer software.

The goal is to create an environment where every screen feels like exploring a living map of human knowledge.

---

## Design Philosophy

Timeless rather than trendy.

Minimal rather than decorative.

Architectural rather than playful.

Every visual element should feel deliberate.

Imagine:

> The Library of Alexandria rebuilt with AI.

---

# Visual Style

## Materials

- Obsidian black
- Deep charcoal
- White marble
- Brushed bronze
- Platinum accents

Avoid bright neon cyberpunk aesthetics.

Avoid glossy consumer-app gradients.

The interface should resemble carved stone enhanced with advanced technology.

---

## Typography

Primary

Modern sans-serif
(clean, geometric)

Secondary

Elegant serif used sparingly for titles and quotations.

The contrast between ancient and modern typography reinforces the identity.

---

## Motion

Animations should be slow and intentional.

Nothing should bounce.

Nothing should feel playful.

Panels should glide into place almost mechanically.

Information should feel like it is being revealed rather than animated.

---

# Navigation

No dashboard.

No overwhelming tables.

The homepage begins with a single question.

```
What would you like to analyze?

[ Event ]

[ Paper ]

[ Company ]

[ Country ]

[ Video ]

[ Market ]
```

Everything else is generated dynamically.

---

# Knowledge Graph First

Traditional finance software is built around tables.

Kyros is built around relationships.

Every object becomes a node.

```
ChatGPT

↓

OpenAI

↓

Enterprise AI

↓

Microsoft

↓

Knowledge Work

↓

Education

↓

Labour
```

The graph is the primary interface.

Tables become secondary.

---

# Agent Interface

Each specialist agent occupies its own workspace.

Rather than tabs such as

Markets
News
Companies

users interact with

- Scout
- Verifier
- Incentives
- Inversion
- Historian
- Market

Each agent contributes to a continuously evolving intelligence report.

---

# The I³ Identity

The formula appears throughout the application.

```
y = I³
```

Not as an explanation.

As a symbol.

Users gradually learn its meaning through repeated exposure.

---

# Information Density

Inspired by Bloomberg.

Beautiful enough to invite exploration.

Dense enough to support professional research.

No wasted space.

Every panel should answer a question.

---

# Overall Feeling

The interface should feel like entering an AI research observatory.

Not a trading terminal.

Not a chatbot.

Not a dashboard.

A place where intelligence accumulates.

A digital Library of Alexandria continuously interpreting the changing world.
